# Web Development Requirements

- For all web development tasks, consult the `modern-web-guidance` skill first and follow its workflow before implementing any code. Search for and retrieve the guidance relevant to the task before making implementation changes.
- When generating any UI component, consult and use the `shadcn` skill. Follow its component discovery, composition, styling, and accessibility guidance throughout implementation.

These requirements apply to all web development and UI component work in this repository.
